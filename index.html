Local workspace
Files are held only for the current browser session. Completed outputs are offered for saving and are not placed in an implicit archive.
No documents stored by default
Application assets may be cached for offline use. Document bytes are not placed in the service-worker cache.

    

  





Local processing
Files stay on this device.
  • Document contents are processed in this browser and are not uploaded to Comment Master or a third-party document service.
  • Filenames, extracted text, metadata, and document hashes are not transmitted.
  • External links found inside documents are listed without being contacted.
  • Offline caching stores application code and optional engines, not the documents you open.
